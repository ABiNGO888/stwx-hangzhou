## 四种进入方式（URL 参数）

| 参数 | 行为 |
| --- | --- |
| 无参数 | 现场同款：出扫码二维码 → 手机扫码确认 → 空格收码 → 前三关 |
| `?qr=1&kiosk=<码>` | 强制直接出扫码门禁（测试码 `a1check`，不碰现场 `hz01`） |
| `?full=1` | 免扫码，从第一关真打，三关通关后进入过场影片与第四关 |
| `?jump=l3` | 免扫码，快进到第三关结算 → 过场影片 → 第四关（看第四关最快路径） |
| `?nosw=1` | 关闭 Service Worker（排查缓存问题时用） |

## 结算顺序（不可颠倒）

1. 第四关胜利画面（白青插图 + 小青配音「姐姐，你终于出来啦，多谢九龙英雄！」）
2. 四关合计计分板（四行：三关 + 第四关）
3. 500 强排行榜

失败分支：
- 前三关中途失败 → 不进第四关，直接「游戏结束 · 止步第N位」
- 第四关未救出白娘子 → 「游戏结束 · 止步第 4 位 · 第四关·九龙救白蛇」，三关分仍计入合计
